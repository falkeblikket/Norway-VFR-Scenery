# Initial catalogue verification — 30 October 2026

The initial catalogues contain **353 listings**:

- **95** freeware scenery/airport listings on
  [ErikHanoy's public creator profile](https://flightsim.to/profile/ErikHanoy),
  including Norway, Iceland, Denmark, Sweden and the Faroe Islands.
- **258** additional Norwegian freeware scenery/airport listings from **105**
  other creator usernames. ErikHanoy duplicates were removed.

Flightsim.to's public website listing data was read to verify titles, numeric
IDs, exact original links, creator usernames, displayed versions, country tags,
categories and simulator labels. Its profile/search pages render these facts
client-side. The same publicly served listing metadata was inspected without
authentication. No private account, cookies, download endpoint, scenery archive,
CAPTCHA bypass or browser automation was used. No retrieval code is in the app.

The Norway listing query contained 372 items. Bush trips and landing challenges
were excluded; the airport/scenery categories were retained. Freeware selection
used the source's explicit `isPremium=false` flag. This is a catalogue snapshot,
not a claim that every Norwegian scenery add-on is represented or still available.

Each record contains its original page URL, check date and a list of fields
supported by that source. The description is a short category summary, not a
copy of the author's full description. The source title is preserved, including
its spelling. Area filters use locality words explicitly present in titles; these
are title-derived labels, **not verified county boundaries or coordinates**.

All entries are marked **partial**. The 2024 field is **reported** for 187
listings and **unknown** for 166. `MSFS2020/24` and `MSFS2024` source labels support
reported 2024 compatibility; a 2020-only label does not establish incompatibility.
No scenery was run in MSFS during this verification.

Licences, redistribution permissions, precise coordinates, package-folder names,
dependencies, conflicts and archive hashes remain **unknown**. Some source
descriptions mention required libraries or special installation instructions;
the user must read the original page. In particular, inclusion in this catalogue
does not guarantee that every download can be installed into Community by this
ZIP-only manager. No versions, licence names or folder names were guessed.

The catalogue records are metadata only. Creators and Flightsim.to retain their
rights to their descriptions, branding and scenery files.
